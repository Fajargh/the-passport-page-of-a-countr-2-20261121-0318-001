A program that draws an invented passport spread for the fictional Republic of Kaveria — a data page with a portrait and a machine-readable zone, entry and exit stamps from three neighbouring countries (Velmara, Ostrovia, Tarnovia) telling one plausible travel history, and a visa-condition stamp — and writes it to `/output/entry.png`. Pure-stdlib Python: the whole spread, including its typography, is drawn in code with no network and no third-party packages.

## Run it

```sh
python3 main.py
```
